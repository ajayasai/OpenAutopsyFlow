# OpenAutopsyFlow

**Evidence-linked autopsy casework, with human-controlled report review.**

Version **0.1.0** · Apache-2.0 · Self-hosted · Pre-production

> This is a working initial release, not a validated clinical/medicolegal system. Use synthetic data until independent security review, departmental workflow validation and operational acceptance are complete. No claim of superiority over every commercial product is supported by the current evidence.

## Publication status

The repository has been created publicly. The application source upload is in progress; this README alone does not constitute an installed or published application.

## Intended release contents

Case intake and structured examination records; evidence links; laboratory and pending-work tracking; report drafts, review comments and separate-account approval; preserved issued reports and linked supplements; case-scoped access controls; export verification; automated tests; and deployment documentation.

Medical opinions remain human-authored. Traceability checks address recorded links and workflow only; they do not validate medical correctness.
